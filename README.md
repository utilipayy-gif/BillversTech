# BillversTech

Production-ready Next.js marketing site for [billverstech.com](https://billverstech.com).

## Local development

```bash
pnpm install
pnpm dev
```

The local site runs at `http://localhost:3001`, so it can run beside UtiliTech. Keep `NEXT_PUBLIC_SITE_URL=https://billverstech.com` in the production environment.
